# WatchMaker Watch Faces

Custom watch faces designed and coded in Lua for the WatchMaker app (WearOS), May 2017 – May 2020.

## The collection

Exported `.watch` files, ready to import into the WatchMaker app:

| File | Description |
|---|---|
| `aw-20.watch` | Apple Watch-style face |
| `aw-20-modded.watch` | Modded Apple Watch-style face |
| `cy-modded.watch` | Modded CY face |
| `fossil-q--digital-inspired--12h.watch` | Fossil Q digital-inspired, 12h |
| `fossil-q--digital-inspired--12h--sbu.watch` | Stony Brook University edition |
| `fossil-q--digital-inspired--12h--ucolor.watch` | User-color variant |
| `fossil-q--digital-inspired--12h--ucolor-duo.watch` | Duo user-color variant |
| `fossil-q--digital-inspired--24h.watch` | Fossil Q digital-inspired, 24h |
| `fossil-q--digital-inspired--24h--anaheim-ducks.watch` | Anaheim Ducks edition |
| `fossil-q--digital-inspired--24h--ucolor.watch` | User-color variant |
| `fossil-q--digital-inspired--24h--ucolor-duo.watch` | Duo user-color variant |
| `movement-example.watch` | Movement/mechanics example |
| `patek-philippe-calatrava-vintage-5116r-white-for-the-gear-s2.watch` | Patek Philippe Calatrava vintage homage (Gear S2) |
| `patek-philippe-calatrava-vintage-5116r-white-modded.watch` | Modded Calatrava homage |

## Use

Import any `.watch` file into the WatchMaker app on your phone to install the face on a WearOS watch.

Source: exported from Jonathan's WatchMaker backup (OneDrive originals untouched).
